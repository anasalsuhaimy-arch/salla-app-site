# موقع محلل المبيعات الذكي

صفحات التطبيق العامة على GitHub Pages: الرئيسية، والأسئلة الشائعة، وسياسة الخصوصية، وشروط الاستخدام.

## store-images/ (لا تمسحها)

صور صفحة التطبيق في متجر تطبيقات سلة: ٥ صور شاشة (٥٢٦×٧٠٠) و٣ صور مزايا (٥١٢×٥١٢). مستخدمة في صفحة التطبيق بسلة، فلا تُمسح ولا تُغيّر أسماؤها. ما لها روابط في صفحات الموقع.

مصدرها ومولّدها في مستودع التطبيق (`marketing/store-images/build.js` على فرع `marketing-assets`). أي تعديل على صورة: ولّدها هناك، وانسخها هنا بنفس الاسم، وأعد ربطها في البوابة.
