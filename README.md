# موقع محلل المبيعات الذكي

صفحات التطبيق العامة على GitHub Pages: الرئيسية، والأسئلة الشائعة، وسياسة الخصوصية، وشروط الاستخدام.

## store-images/ (لا تمسحها)

صور صفحة التطبيق في متجر تطبيقات سلة: ٥ صور شاشة (١٠٥٢×١٤٠٠) و٣ صور مزايا (٥١٢×٥١٢) والبانر الترويجي `banner.png` (١٨٠٠×٦٠٠). مستخدمة في صفحة التطبيق بسلة، فلا تُمسح ولا تُغيّر أسماؤها. ما لها روابط في صفحات الموقع.

مصدرها ومولّدها في مستودع التطبيق (`marketing/store-images/build.js` و`banner.js` على فرع `marketing-assets`). أي تعديل على صورة: ولّدها هناك، وانسخها هنا بنفس الاسم، وأعد ربطها في البوابة.
